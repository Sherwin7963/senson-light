# OWELL Industrial - LED Sensor Light Website

B2B LED infrared sensor light manufacturer website built with React + TypeScript + Tailwind CSS.

## Features

- Responsive B2B marketing website (English / 中文 / Español / 日本語)
- Product catalog with categories and detail pages
- Admin dashboard for content management
- Contact/Quote inquiry form
- News/Blog module
- GDPR Cookie consent
- SEO optimized with meta tags and structured data

## Deployment

This package is ready for GitHub Pages deployment:

1. Upload all files to your repository's `gh-pages` branch or docs/ folder
2. Enable GitHub Pages in repository settings
3. The site works with BrowserRouter (History API) using the `404.html` SPA fallback

## Admin Access

- Visit `/admin` to access the management dashboard
- Default password: `admin123` (change this for production)

## Tech Stack

- React 19 + TypeScript
- Tailwind CSS 4
- React Router DOM 7
- Vite 8
