# Data Directory

This directory is populated automatically when you sync content from the admin panel
(GitHub Sync → Sync Entire Site).

Files created after sync:
- products.json, advantages.json, testimonials.json, features.json
- hero-slides.json, about.json, news.json, categories.json
- footer.json, seo.json, privacy.json, translations.json

If these files are missing (before first sync or if sync fails),
the website falls back to its default bundled data automatically.
